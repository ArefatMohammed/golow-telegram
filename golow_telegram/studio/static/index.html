    Step-by-step OBS setup
    1. Settings → Video: base and output canvas 1080×1920.
    2. Docks → Custom Browser Docks: add This panel and sign in once inside the dock.
    3. Add a Browser Source for Overlay at the canvas size, and tick Control audio via OBS.
    4. Add Live board and Reveal the same way, e.g. a “Reveal” scene with the reveal over your camera.
    5. Tools → WebSocket Server Settings → Enable, then connect above to switch scenes from here.
    6. Scene links carry a key that expires; copy fresh ones when the note above says so.
