    OBS setup

    Step-by-step OBS guide
    1. Settings → Video: base and output canvas 1080×1920.
    2. Docks → Custom Browser Docks: add This panel and sign in once inside the dock.
    3. Add a Browser Source for Overlay: width 1080, height 1920, tick Control audio via OBS.
    4. Add Browser Sources for Live board and Reveal the same way, in their own scenes or above the overlay.
    5. Pick the auction here: the overlay follows. Use the preview to check before going live.
    6. Scene links contain a key and stop working after it expires. Copy fresh ones when the note above says so.
    7. The panel drives the scenes only when it runs inside OBS (dock) or in the same browser as the scenes.
